# MediaHub — Issue Tracker

This is the **public issue tracker** for [MediaHub](https://peterknight.digital/docs/mediahub/), a ProcessWire module for managing a media library inside the admin.

MediaHub's source code is maintained in a private repository. This public tracker exists so users can report bugs, suggest improvements, and follow along with progress.

---

## Before you submit

- **Search first.** Your issue may already be reported or fixed. Check both open and closed issues.
- **Use the latest version.** Confirm the issue exists on the most recent release before reporting.
- **One issue per report.** Please don't bundle multiple unrelated problems into a single issue.

---

## Reporting a bug

A good bug report includes:

1. **MediaHub version** — visible in *Modules → MediaHub* in the ProcessWire admin.
2. **ProcessWire version** — visible in the admin footer (e.g. `3.0.229`).
3. **PHP version** — e.g. `8.2`.
4. **Browser** — if it's a front-end / admin UI issue.
5. **Steps to reproduce** — clear, numbered steps that consistently trigger the problem.
6. **Expected behaviour** — what should happen.
7. **Actual behaviour** — what actually happens. Screenshots or screen recordings are very welcome.
8. **Any relevant template or field configuration** — e.g. which inputfield type, field settings, template structure.

---

## Requesting a feature

Feature requests are welcome. Please describe:

- **The problem you're trying to solve** — context is more useful than a solution spec.
- **Your proposed solution** (optional) — how you imagine it might work.
- **Alternatives you've considered** (optional).

---

## Issue labels

| Label | Meaning |
|---|---|
| `bug` | Something isn't working correctly |
| `ux` | User experience improvement |
| `feat` | New feature or enhancement |
| `documentation` | Docs addition or correction |
| `P1` | Critical — blocks usage or causes data issues |
| `P2` | High — noticeable issue, common workflow affected |
| `P3` | Medium — nice to have, lower urgency |
| `easy` / `medium` / `hard` | Estimated implementation effort |
| `possibly-fixed` | May be resolved — awaiting confirmation |
| `needs-info` | Waiting on more information from the reporter |
| `confirmed` | Reproduced and confirmed by maintainer |

---

## Support

This tracker is for **bugs and feature requests only** — not for general support questions.

For general help, visit the [ProcessWire community forum](https://processwire.com/talk/) and search for MediaHub, or check the [MediaHub documentation](https://peterknight.digital/docs/mediahub/).
